# Context

Swift QR is a Swift 6 QR encoding library and `qr-gen` CLI supporting numeric, alphanumeric, and byte encoding, Reed-Solomon correction, matrix construction, and SVG/PNG rendering. It is tested on Linux and macOS and publishes DocC through Pages. It has no prior SpecSync threshold or companions.
